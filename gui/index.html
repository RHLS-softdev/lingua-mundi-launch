How to use this dictionary

  1. Type a word — Japanese or English — in the search box.
  2. Results appear as you type; press Enter or tap a suggestion to open it.
  3. You'll see the word's readings, meanings, kanji details, and related forms.
  4. Switch the language button (日本語 / EN) to search in the other direction.
  5. Tap ✕ to clear the search and start again.

Everything is looked up in the Lingua Mundi database — every entry traces to a named source (JMdict, KANJIDIC2, WordNet, J-UniMorph). No guesses.
